# Wireless Choices plugins for Claude

Plugin marketplace from [Wireless Choices](https://wirelesschoices.com.au), an Australian telco plan comparison site.

## Plugins

- [`wireless-choices`](./wireless-choices/) — search and compare Australian mobile, prepaid, mobile broadband and nbn home internet plans listed on Wireless Choices, through our remote MCP server. Read-only, no account needed. Plan data is general information, not advice; confirm details with the provider before you sign up. See the plugin README for accuracy, privacy and licence terms.

## Install in Claude Code

```
/plugin marketplace add wireless-choices/claude-plugins
/plugin install wireless-choices@wirelesschoices
```

Documentation: https://wirelesschoices.com.au/tools/ai-assistants

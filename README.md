# Wireless Choices plugins for Claude

Plugin marketplace from [Wireless Choices](https://wirelesschoices.com.au), an Australian telco plan comparison site.

## Plugins

- [`wireless-choices`](./wireless-choices/) — search and compare Australian mobile, prepaid, mobile broadband and nbn home internet plans listed on Wireless Choices, and check community outage reports and resolved carrier outage history, through our remote MCP server. Read-only, no account needed. Plan and outage data is general information, not advice; confirm plan details with the provider before you sign up, and check the provider's own status page for current network status. See the plugin README for accuracy, privacy and licence terms.

## Install in Claude Code

```
/plugin marketplace add wireless-choices/claude-plugins
/plugin install wireless-choices@wirelesschoices
```

Documentation: https://wirelesschoices.com.au/tools/ai-assistants
